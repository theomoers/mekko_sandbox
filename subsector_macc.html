Bars are sorted by marginal abatement cost for the selected year. Width = abatement potential, height = cost in US$/tCO2e.

How to Read the Chart

Each block is one abatement lever for this subsector in the selected year.

Block width shows abatement potential (BtCO2e). Block height shows marginal cost (US$/tCO2e).

Blocks below the dashed zero line indicate cost-saving abatement options.

Color Legend

Cost-saving (< 0 US$/tCO2e)
Low cost (0 to 80 US$/tCO2e)
Medium cost (80 to 180 US$/tCO2e)

Clicked Block Details
